Sentinel

On-chain guardrails for AI agents

Built on Monad · Hackathon 2026

THE PROBLEM

AI agents can send your money anywhere

Autonomous AI agents execute transactions on behalf of users. But there's no safety layer. One bad decision, one prompt injection, one compromised key — and funds are gone. Irreversibly.

💸 No spending limits

Agents can drain wallets in a single transaction

🎯 No address restrictions

Agents can send to any address, including attackers

⏱ No time delays

Large transactions execute instantly — no cancel window

🚨 No emergency stops

No way to pause a compromised agent mid-execution

THE SOLUTION

Sentinel: enforce guardrails before execution

Users define on-chain policies. Every agent transaction must pass through Sentinel's smart contracts — or it reverts.

💰 Spending Limits

Max per-tx and per-period caps. Agent can't overspend.

📋 Whitelists

Only approved contract addresses. No rogue interactions.

⏳ Time-locks

Large txs delayed. Users can cancel during the lock window.

🛑 Circuit Breaks

Auto-pause on suspicious activity. Manual emergency stop.

MONAD PRIMITIVES

Built on Monad's unique capabilities

🔐 P256 Precompile

Passkey-based policy auth. Users authorize changes with Face ID / Touch ID — no seed phrases needed.

🆔 ERC-8004

Trustless on-chain agent registry. Any app can verify an agent's guardrails before interacting.

🔒 BTX Encrypted Mempools

Spending limits and whitelists stay private until execution. No frontrunning your guardrail config.

⚡ 10,000 TPS

Monad's throughput means real-time guardrail checks without slowing down agent execution.

ARCHITECTURE

Clean separation of concerns

📄 SentinelRegistry.sol

ERC-8004 agent registry. Register, deactivate, query agents and their policy hashes.

🛡 SentinelGuard.sol

Core guardrail engine. Spending limits, whitelists, time-locks, circuit breaks. The ONE entry point for agent execution.

🔐 P256PolicyAuth.sol

Passkey authorization via Monad's P256 precompile. WebAuthn signatures for policy changes.

🖥 Frontend

React + Vite + TypeScript. 6 pages. Multi-wallet (EIP-6963). Light theme. Mobile-first.
